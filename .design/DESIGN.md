# Flip7 Design System
Retro-playful, teal-coral-gold design system crafted for Flip7. Inspired by packaging with vintage warmth, modern mobile UX, bold, joyful, and tactile elements.

## Overview
Flip7 is a retro-playful, teal-coral-gold design system. The visual language is bold, joyful, and tactile -- combining bubbly energy with competitive gamification patterns. Every element feels like a tactile game piece you want to interact with.

---

## Colors
- **Primary Teal** (`#2BA8A2`): Main UI, brand headers, active tabs, avatars, progress bars
- **Primary Light** (`#3CC4BD`): Hover states, lighter accents
- **Primary Dark** (`#1E8C86`): Deep backgrounds, text on light surfaces, borders
- **Primary BG** (`#E8F6F5`): Subtle teal tint for backgrounds
- **Accent Gold** (`#FFD23F`): CTAs, highlights, hero badges, star moments, buttons
- **Accent Light** (`#FFE47A`): Soft gold tints, active states
- **Accent Dark** (`#E6B800`): Gold hover states, depth
- **Coral** (`#EF6C4A`): Urgent/Alert state, warnings, ranking #3, energy, delete/cancel
- **Coral Light** (`#FF8A6A`): Soft coral tints
- **Coral Dark** (`#D45233`): Coral depth, hover
- **Cream** (`#FFF8E7`): Card backgrounds, input surfaces, pill badges
- **Sky Blue** (`#5DADE2`): Special bonuses, info states
- **Surface Base** (`#EFF8F7`): Page background
- **Surface Card** (`#FFFFFF`): Card backgrounds
- **Success** (`#27AE60`): Positive states, paid invoices
- **Error** (`#E74C3C`): Error states

## Typography
- **Cairo** (Arabic primary font) combined with Extra-bold (800) and generous letter-spacing for headlines.
- **Display**: 36px - 44px extra-bold
- **h1**: 28px - 32px extra-bold
- **h2**: 22px - 24px extra-bold
- **h3**: 18px - 20px bold
- **body**: 15px - 16px medium
- **sm**: 13px - 14px medium
- **xs**: 11px - 12px medium

- `shadow-md`: 0 4px 16px rgba(0, 0, 0, 0.12)
- `shadow-card`: 0 4px 20px rgba(43, 168, 162, 0.12)
- `shadow-coral-glow`: 0 4px 20px rgba(239, 108, 74, 0.35)
- `shadow-teal-glow`: 0 4px 20px rgba(43, 168, 162, 0.35)
- `shadow-accent-glow`: 0 4px 20px rgba(255, 210, 63, 0.45)
- `shadow-sky-glow`: 0 4px 16px rgba(93, 173, 226, 0.35)

## Tactile Components & UI Principles
1. **Pill-shaped buttons (`rounded-full`)**: Touch targets with bounce hover/active scale.
2. **Cream (`#FFF8E7`) input surfaces**: Warm, high-contrast, tactile inputs with teal focus rings.
3. **Colored Accent Borders**: Cards feature 4px/6px solid left/right accent border representing status.
4. **Dashed Section Dividers**: Playful dashed borders for sections.
5. **No plain black shadows**: Use colored glow shadows for interactive and highlighted elements.
