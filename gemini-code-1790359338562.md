### Key Architectural & Design Guidelines
1. **Typography & Styling (Google Fonts):**
   - Embed Google Font **"Cairo"** via standard stylesheet link in `src/app/layout.tsx` (`https://fonts.googleapis.com/css2?family=Cairo:wght@400;600;700;800&display=swap`).
   - Configure Tailwind (`tailwind.config.js`) to set `Cairo` as the default font family for Arabic text (`font-sans`).
   - Clean, high-density SaaS aesthetic inspired by modern UI design systems (Linear/Stripe style).
2. **Mobile-First Responsive Design:**
   - Desktop: Sidebar/Top navigation and structured tables.
   - Mobile (< 768px): Fixed **Bottom Navigation Bar** (`fixed bottom-0 left-0 right-0 z-50 bg-white border-t`) with 5 touch-friendly icons: (الرئيسية، الفواتير، التشغيل، المخزون، المزيد). Tables collapse into scannable touch-friendly cards.
3. **Offline Resilience & Conflict-Free Numbering:**
   - Bundled local SVG icons (`lucide-react`). Zero external CDN dependencies except Google Fonts.
   - SQLite local database (`prisma/dev.db`).
   - Invoices: `[PREFIX]-INV-[YYMMDD]-[DAILY_COUNTER]` (e.g. `KHW-INV-260925-001`).
   - Contracts: `[PREFIX]-CNT-[YYMMDD]-[COUNTER]` (e.g. `KHW-CNT-260925-001`).
   - Immutable primary keys using `cuid()`.
